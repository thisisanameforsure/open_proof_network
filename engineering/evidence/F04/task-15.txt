Three things the reading found that the page does not say (Q17; the gate's to settle, not the site's)
  1. A proposer's `speculative` record outlives a merged proof: derive_statuses takes the latest record over
     the artifact, and nothing writes a later record when a proof merges. As the code reads; not seen live.
  2. `stale` has no mechanical exit: revise writes the record and D-18's re-run is unbuilt, so a stale node
     leaves that state only when the curator revises it too.
  3. `disputed` is a schema value with no command or route that writes it.
