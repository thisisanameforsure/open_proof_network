(c) Annex provenance cut: "sources read via erdosproblems.com,, 2026-10-08T13:06:59Z".
    Cause: model.parse_prose split the front matter on newlines and partitioned each line on
    ":", so a YAML plain scalar folded over three lines (annex/v2's model_and_tooling, written
    by the service's YAML dump) kept its first physical line only — ending in the comma the
    label then followed with its own ", ". Fix: model._front_matter_strings reads the head as
    YAML with PyYAML's BaseLoader (already a dependency; C5: nothing new), which builds only
    strings, lists and mappings — so a folded value is read whole, a timestamp stays the text
    written (safe_load would make it a datetime and print it back differently), and "null"
    stays the word _YAML_NULLS already reads as nothing. A head that is not YAML (a value with
    a second colon) is read line by line as before, so a malformed head still takes no page
    down and loses no field it states.
(d) Outline title cut mid-word: "… a reading of the formal statement agai".
    Cause: render.outlines_block sliced the first line with [:140]. Fix: render.clip cuts at
    the last space within TITLE_LIMIT (140) and appends "…" (the convention dag.py and
    gate/opn_gate/context.py use); a dangling comma or dash before the mark is dropped; a title
    with no space is cut at 140 and still marked.
(e) Double full stop: "… with only finitely many exceptions.. Imported from formal-conjectures".
    Cause: not the informal statement but the record's *title*: target.html's provenance line
    is f"{esc(title)}. " + source line, and 16 live titles already end a sentence ("…
    exceptions.", "Let $k ≥ 2$.", "Is … irrational?"). Fix: render.sentence adds the full
    stop only when the title does not already end in . ? ! … (looking past a closing bracket
    or quote, so "(see below.)" counts).
