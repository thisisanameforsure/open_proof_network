account-free identity, POST /proposals/variant 201, pull request #8 with seven files under
nodes/variant-93e79cb5/, the pseudonym as author and the App as committer, the gate green, the
merge as a merge commit. Then the post-merge run on the merge commit (34608433726) FAILED in
its products step:

  opn-gate: products not written: root is ambiguous: 2 nodes have no dependents
  (tutorial-and-swap, variant-93e79cb5); declare one in targets/<id>/status/ (target-status/v1 root)

A D-30 variant has no dependents by construction, so the first merged variant made the DAG's
sink ambiguous and F03's root inference refused, as designed (F03-Q5): the mechanism for this
case is a target-status/v1 record declaring the root. The smoke, meanwhile, had read the wrong
push run (the earlier F08-T6 products push, not the merge's) and reported the node ABSENT — a
defect in the smoke's run lookup, recorded below.

(postmerge only runs for a merged pull request), so it was reverted and re-landed as pull
request #9 by the listed curator — targets/tutorial/status/2026-09-11-1.yaml declaring root
tutorial-and-swap, status resolved, claimable true, which is what the products already
