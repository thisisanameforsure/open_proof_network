== The audit of every call the seam makes with an App token (GitHub's "Permissions required
   for GitHub Apps" page, read 2026-10-04) ==
  method                   repo(s) called on            endpoints                                    token asks for
  head_sha                 graph                        GET git/ref/heads/{b}                        contents: read
  list_dir                 graph                        GET contents/{path}?ref=                     contents: read
  is_ancestor              network (public fallback)    GET compare/{a}...{b}                        contents: read
  push_branch              graph (submit, racers),      GET git/ref, GET git/commits, POST git/trees, contents: write
                           scratch (precheck)           POST git/commits, POST git/refs | PATCH ref
  delete_branch            graph (withdraw)             DELETE git/refs/heads/{b}                    contents: write
  open_pull_request        graph                        POST pulls                                   pull_requests: write
  close_pull_request       graph (withdraw)             PATCH pulls/{n}                              pull_requests: write
  list_open_pull_requests  graph                        GET pulls?state=open                         pull_requests: read
  get_pull_request         graph                        GET pulls/{n}, GET pulls/{n}/reviews,        pull_requests: read,
                                                        GET actions/runs, GET actions/runs/{id}/jobs actions: read
  latest_artifact          graph                        GET actions/runs/{id}/artifacts, GET .../zip actions: read
  dispatch_workflow        scratch                      POST actions/workflows/{w}/dispatches        actions: write
  find_run                 scratch                      GET actions/workflows/{w}/runs               actions: read
  download_artifact        scratch                      GET actions/runs/{id}/artifacts, GET .../zip actions: read
  (metadata: read is implied on every token)

So the union per repository is:
  graph:   contents: write, pull_requests: write, actions: read        (no checks permission is
           used: get_pull_request reads actions/runs, not check-runs — F07-T16's own note)
  scratch: contents: write, actions: write
  network: contents: read (the compare call only)
but no single token carries the union: each call mints (once per hour, cached per
(repository, permission set)) the narrowest set above, so a read's token can never write.

comment_on_pull_request (added on branch audit-e-tools, not in this branch): POST
issues/{n}/comments is listed on GitHub's permissions page under BOTH "Issues: write" and
"Pull requests: write"; for a comment on a pull request, pull_requests: write is the documented
alternative. At merge, that method should call `self._api(repo, PULLS_WRITE)`. If probe P6b below
answers 403, use `(("issues", "write"), ("pull_requests", "write"))` instead (and the App must
hold Issues: write on the graph installation).

== The fix ==
githost: Permissions constants (CONTENTS_READ/WRITE, PULLS_READ/WRITE, PULL_STATE,
ACTIONS_READ/WRITE); _api(repo, permissions) and _installation_token(repo, permissions); the
token request body {"repositories": [<name without owner>], "permissions": {...}}; tokens cached
per (repo, permissions). Restated: test_finding_submissions_cold_latency's concurrent-mint test
now names the permission set it mints.

Proposed Q (next free F06 Q): "An installation token is minted for one repository and the
permissions of the call that uses it, and cached per (repository, permission set): contents read
for refs, listings and compare; contents write for the Git Data API and branch deletion;
pull_requests write to open, close and comment on a pull request; pull_requests and actions read
for a pull request's state; actions read for runs and artifacts; actions write for dispatch. The
App's grant (C8) is the union, graph: contents write, pull_requests write, actions read; scratch:
contents write, actions write; no checks permission is used. An empty token request, which GitHub
answers with the App's whole grant on every installed repository, is never made."
