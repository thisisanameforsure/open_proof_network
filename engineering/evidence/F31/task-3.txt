## What was built

- `gate/opn_gate/shelving.py`: `arrivals(nodes, routes)` — ``(P, route)`` for every hole of a
  merged decomposition of ``P`` as `products.route_holes` matches them (the same matching
  `graph.json`'s `decompositions` publishes; never the `--h` prefix), plus ``(P, None)`` for a
  hole child no decomposition names; a superseded parent's arrivals are left out (its revision
  carries them, by `graph.load_nodes`'s fold). `own_standing(nodes, n, exclude=)` — the node's
  own records latest per key, and along `graph.same_statement_chain` where it has none of its
  own (F31-Q8). `derive(nodes, *, root, used, exclude=, routes=)` — one memoised top-down pass:
  own `scope: node` record decides (shelved void on the root and on a used node; unshelved
  exempts); else shelved iff not root, not used, ≥1 arrival and every arrival cut (parent
  shelved, or that route retired by the parent's latest record naming it); the object carried
  is the one that reached the node, `via` the node whose directory holds the record (a
  same-statement revision inherits the predecessor's record *and* names the predecessor as
  `via`, since `record` is relative to that directory). A cycle through a lemma arrival reads as
  not cut (a node is never shelved by its own reflection).
- `gate/opn_gate/products.py`: `route_holes(nodes, node_id)` extracted from
  `decompositions_of` (which now calls it) so the derivation and the published decompositions
  share one matching; `in_frontier` returns False for a shelved node (after the superseded
  check, before anything else).
- `gate/opn_gate/graph.py`: `load_target` fills `NodeFacts.shelved` from `shelving.derive`
  after the statuses are derived (statuses never read it). `context.build` already repeats the
  row on the node and each dep (T1), so both bundle builders agree with no further change.
- `gate/tests/shelving_support.py`: `Tree.revise` (a same-statement D-8 revision).
- `gate/tests/test_shelving.py` (new): 18 tests — the fixture is ``A`` decomposed into ``A--h1``
  and ``A--h2`` (route 1), ``A--h2`` into ``A--h2--h1``; a second route of ``A`` (``A--h3`` plus
  ``A--h2`` restated as a lemma) and a route of ``T`` using ``A--h1`` as a lemma (the
  erdos-1094 shape) are added per test.

## Decisions / proposed Q entries

- proposed Q: **two retirements are two keys.** A route record's key is its route; the node's
  own `scope: node` record is another key. Retiring route 2 does not lift route 1's retirement,
  and `unshelved` lifts the key it names (`scope: route` with the route, or `scope: node`). The
  brief's "the node's own latest record" read literally would un-retire route 1 when route 2 is
  retired; `test_retiring_every_route_shelves_every_hole_and_what_is_beneath_them` pins the
  reading. The service's "an act that changes nothing" check should use the same key.
- proposed Q: **`via` is the record's home.** For an inherited shelving `via` is the node
  whose `shelving/` directory holds the record, which is what makes `record` resolvable; a
  same-statement revision that inherits its predecessor's record names the predecessor.
- proposed Q: **a withdrawal cannot yet name a shelving record.** `withdrawal/v2`'s
  `withdraws` pattern admits `status/`, `defects/`, `gloss/` and `explainer/` only, so no valid
  withdrawal names `shelving/<file>` today; `shelving.load` honours
  `records.withdrawn_names(node_dir, "shelving")` already, so a `withdrawal/v3` adding the
  prefix (a lead/contract change under D-34) makes F31-Q9's rule live with no code change
  here. The test covers the loader's exclusion path (`exclude=`), which the gate's T5 refusal
  also uses for a pull request's own records.
- A superseded parent's arrivals are skipped (otherwise shelving a revision could never cut the
  holes the fold carried over, since the old node's own `holes` still name them).
- `route_holes` is an extraction from `decompositions_of`, byte-for-byte the same matching
  (test_decompositions, test_finding_graph_lemmas and the goldens all pass unchanged); noted
  because the brief limited products edits to `in_frontier` and the `shelved` fill.
