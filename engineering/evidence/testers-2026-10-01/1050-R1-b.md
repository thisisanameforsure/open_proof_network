## Mathematics
Notation: n >= 1, y_k = 2^k, D_k = prod_{l != k, l<=n} (1 - 2^{l-k}), A_k(x) = -prod_{t=1..n-1}(1 - x 2^{t+k}) / D_k,
h_i(x) = 1/(1 - x 2^i), S1(x) = sum_{k<=n} A_k(x) sum_{i<=k} h_i(x); head_integral is about S1(8/3).
alpha_j = coefficients of prod_{t=1..n-1}(1 - 2^t y); H_e = complete homogeneous symmetric polynomial h_e(2,4,...,2^n) (integer; H_e = 0 for e<0).
Lagrange fact (L): sum_k 2^{ke}/D_k = H_e for every integer e >= -(n-1).
**Identity**: S1(x) = E(x) + sum_{i=1..n} b_i h_i(x) with
  E(x) = sum_{j=1..n-1} (2^j - 1)^{-1} sum_{j'=j..n-1} alpha_{j'} (H_{j'} - H_{j'-j}) x^{j'-j}   (an integer polynomial over each 2^j - 1),
  b_i = sum_{k<=n} A_k(2^{-i}) = sum_{k>=i} A_k(2^{-i})   (terms k<i vanish: a factor 1 - 2^{t+k-i} with t = i-k is 0).
Proof: x^{j'} h_i(x) = 2^{-ij'} h_i(x) - sum_{s<j'} 2^{-i(j'-s)} x^s; sum over i<=k, k, j' and use (L) on the geometric sums
sum_{i<=k} 2^{-i j} = (1 - 2^{-kj})/(2^j - 1).
**Integrality**: each (2^j - 1), j <= n-1, divides the Mersenne block M_n (1050-B's hdvd), so 3^{n-2} M_n E(8/3) in Z.
b_i is an integer: b_i = -(+-2^{C(i,2)}) * (divided difference of the integer polynomial y^{n-1} prod_{t=i..n-1}(1 - 2^t y) at the integer nodes 1,2,...,2^{n-i}).
3^n P(n) h_i(8/3) = 3 prod_{i' != i}(3 - 8 2^{i'}) in Z. Hence 9^n P(n) M_n S1(8/3) in Z: **no factorial needed**.
Numerics: `num.py` confirms identity, b_i in Z, denominators 1, for n=1..13.
