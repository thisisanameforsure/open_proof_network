# 402-R5-b FINDING: the seven residual sizes below 200000 (2026-10-01)

## Verdict
**All seven residual sizes (63, 105, 111, 153, 165, 679, 680) are closed, in Lean, fast-checked at the pin
(lean-4.33.1, exact, okay true, no sorry, no native_decide), with no second prime q and no per-size brute force.**
The finite range is now complete for every size 10 ≤ n ≤ 200014 (10..680 here, 681..200014 by 402-R4-c's 18
window files), including sizes that are prime or prime + 1.

The window condition (2n − p)² ≤ n was never what the proof needed. It is used in exactly one place, the
arithmetic step of the rectangle lemma, and what that step needs is a *divisor-gap* property of each α in the
window. Stating the criterion with that property gives:

> **Generalised criterion (`r5b_gen_criterion`, one declaration, 397 lines).** Let A be a set of n positive
> integers, p prime, n < p < 2n, 2(2n − p) ≤ n + 2. Suppose every α with p − n < α < n satisfies
> (i) some prime q ≥ n/3 divides α·(p − α), or
> (ii) there are no x < y with x·y ∣ α and α·y < n·x.
> Then A has a pair with gcd(a,b) ≤ a/n, **or** some prime q ≥ n/3 divides an element of A.

The second disjunct of the conclusion is exactly the second disjunct of the open hole
`erdos-402--h3-v2--h1--h1--h1` (∃ p prime, |B| ≤ 3p, p ∣ a), so it costs nothing there.

For 679 and 680 the exclusion is necessary, not a convenience: {650·25, 677·25, 650·26, 677·26} has every cross
quotient below 679 (max 677), so the rectangle lemma is genuinely false for that shape, and the count is then
exactly tight (16 doubled classes needed, 15 shapes, one of them able to host two). The prime 677 is what kills it.
