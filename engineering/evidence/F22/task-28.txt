F22-T28 — an anchored explainer whose outline is not rendered yet answers 409 products-pending
(2026-11-19 nine-agent run, finding B9)

Finding
-------
During the post-merge lag (B2), POST /glosses (dry run included) refused an explainer whose
sections name outline steps with `explainer-step-unknown` "...named on Proof.lean, which has no
outline to name steps of". The outline is written by its own job after the post-merge job pushes
(graph gate.yml `outline`, F19-T4), and the service then reads main through its own window, so
the refusal lasted 1–2 minutes past the outline's commit too. Three agents read it as permanent.

The three that passed pin what must not change: a wrong step against an outline in hand is still
explainer-step-unknown, an explainer naming no step files at once (201), an unmerged artifact is
still explainer-proof-unknown.

Fix
---
api/opn_api/glosses.py: `check_outline_rendered`, run after the scratch tree is materialised and
before the gate's pre-flight. When the subject is an explainer, its text has a level-2 heading
ending in a `{steps: ...}` anchor (`names_steps`), the proof is a merged artifact of the node
(`explainers.merged_artifacts`) and the service holds no outline of it (`explainers.outline_of`),
the answer is the existing `precheck.awaits_render` helper's 409 products-pending (Retry-After
header, shape unchanged), with details {node_id, proof, artifact, outline}. The message says the
same words can be filed once the outline is there and words naming no step can be filed now.
gate/opn_gate/explainers.py: the heading and anchor regexes became public (ANCHOR_RE,
HEADING_RE) so the service reads anchors with the gate's own patterns. The gate's own refusal at
merge is unchanged (a merge without the outline is still explainer-step-unknown there).

Existing test restated: api/tests/test_glosses_route.py::
test_an_explainer_of_an_unknown_proof_or_step_is_refused asserted explainer-step-unknown for an
anchored explainer of the merged Proof.lean with no outline — the defect itself. It now asserts
products-pending there, adds the case "outline in hand, step absent → explainer-step-unknown",
and keeps the rest.
