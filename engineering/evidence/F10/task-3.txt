   and exits 1, while BSD tr on this laptop accepts the same set and prints the right answer.
   The tag is now bash's own substitution, which needs no external program, and
   gate/tests/test_pins.py runs the real line out of the workflow and asserts the expression
   contains no pipe.

   succeeded). The image was fine; the workflow's own check was wrong. pyproject.toml declares no
   build backend on purpose, so opn_gate is never installed and every entrypoint puts it on the
   path — pregate.sh, reproduce.sh and devcontainer/post-create.sh all export
   PYTHONPATH=<network>/gate. The step does the same now, and runs the CLI rather than importing
   the package.

-----------------------------------------------
