== 2. The change ======================================================================
gate/tools/rehearsal.py
  variable_names(text)            the set of vars.<NAME> in a workflow's text: ${{ vars.X }} with
                                  or without spaces, a bare if:, inside format(...) or after &&.
                                  Not secrets.X, env.X, steps.vars.outputs.X (the name must not
                                  follow a word character, '.' or '-').
  workflow_variable_names(graph)  the union over <graph>/.github/workflows/*.yml and *.yaml.
  parse_variable_listing(stdout)  gh variable list --json name's answer as a set, or None when it
                                  is not a JSON list of {"name": str}.
  gh_variables(repo)              (listing, "") or (None, why): gh not on PATH, gh exited non-zero
                                  (stderr quoted), timed out, or answered no list of names.
                                  Fixed argv, no shell, 60 s timeout; it only reads.
  repository_variables(names, listing, unavailable)
                                  "skipped" (not attempted, names gh and the reason) when listing
                                  is None — even for an empty set, since not looking is never a
                                  pass; "failed" naming every missing variable once, and none of
                                  the defined ones; "ok" otherwise. Names compare
                                  case-insensitively: GitHub's docs say variable names "are case
                                  insensitive when referenced" and are stored uppercase.
  variables_step(record, graph, repo)
                                  the step "repository-variables": skipped without --graph and
                                  --repo; failed when the checkout has no workflows or they cannot
                                  be read; otherwise the check above.
  run() now calls drive() (the old body) and then variables_step, so the step is recorded last
  and also when the frontier step fails and the service steps stop early.
  New flags --graph DIR and --repo OWNER/NAME. There is no default for either: a default checkout
  path would make the fast-tier tests call the real gh.
