The open core of Erdős #1094: what is known about exceptions with n ≥ k², and an equivalent form that may help decompose it.

**1. What this statement is.** It asks for a bound K such that every exception with n ≥ k² (that is, every C(n,k) with n ≥ k² and no prime factor ≤ n/k) has k ≤ K. Together with the fixed-k statement (for each k the exceptions with n ≥ k² are finite, indeed n < k! + k) it gives finiteness of all exceptions with n ≥ k². It is a weak, "finitely many" form of Ecklund's conjecture (Pacific J. Math. 29 (1969) 267–270: whenever n > k², C(n,k) has a prime factor p < n/k) and of Selfridge's (Notices AMS 1977: the same for n ≥ k² − 1, with the single exception C(62,6)). Both are open. Erdosproblems #384 records that only the weaker bound p ≪ n/k^c, for some constant c > 0, is known.

**2. The known exception.** C(62,6) = 61474519 = 19 · 29 · 31 · 59 · 61, and 62/6 ≈ 10.3. Its six factors split as 62 = 2·31, 61, 60, 59, 58 = 2·29, 57 = 3·19: the parts of 62, …, 57 made of primes ≤ 10 are 2, 1, 60, 1, 2, 3, whose product is 720 = 6!. A mechanical search of every k ≤ 200 and k² ≤ n ≤ 200000 (Kummer's carry criterion) finds no other exception with n ≥ k². Erdős, Lacampagne and Selfridge (Math. Comp. 61 (1993) 215–224) searched much further (k up to about 12000 for the related bound with p > 5, as summarised on MathOverflow 368183) and report none.

**3. An equivalent form (elementary, checked numerically).** Fix n ≥ k² and write B = ⌊n/k⌋, so B ≥ k. For each i < k write n − i = s_i · r_i, where s_i is the part of n − i made of primes ≤ B and r_i the rest. Then n(n−1)…(n−k+1) = k! · C(n,k), and all primes of k! are ≤ k ≤ B, so the B-smooth part of the product, ∏ s_i, equals k! times the B-smooth part of C(n,k). Hence: (n, k) is an exception if and only if ∏ s_i = k!. Moreover each r_i is 1 or a single prime > n/k (two such primes would multiply to more than (n/k)² ≥ n), and when r_i is a prime, s_i = (n − i)/r_i < k. So an exception is a run of k consecutive integers below n in which every term is either B-smooth (and then at most k!) or a prime > n/k times a cofactor < k, with the smooth parts multiplying to exactly k!. (I checked this equivalence against a direct computation for every k ≤ 25 and k² ≤ n < 4000: no mismatch.) The term m = k·⌊n/k⌋ is always B-smooth, so m divides k!, which is the fixed-k bound n < k! + k.

**4. Every exception is a good binomial coefficient, so the open range is g(k) ≤ n < k! + k.** For n ≥ k², n/k ≥ k, so an exception has no prime factor ≤ k: C(n,k) is *good* in the sense of Ecklund–Erdős–Selfridge. Hence an exception with n ≥ k² has n ≥ g(k), the least n > k + 1 with C(n,k) good, and g(k) ≫ exp(c (log k)²) (Konyagin, Mathematika 46 (1999) 41–55). Combined with the fixed-k bound, every exception with n ≥ k² lies in g(k) ≤ n < k! + k. On top of goodness, an exception needs the window n − k + 1, …, n to contain no multiple of any prime q with k < q ≤ n/k (such a q does not divide k!, so it would divide C(n,k)). Heuristically a window of length k avoids the multiples of a prime q > k with probability about 1 − k/q, so the chance of avoiding all primes in (k, x], x = n/k, is about exp(−k Σ 1/q) ≈ (log k / log x)^k; this is what makes finitely many exceptions plausible, and it is a heuristic, not an argument. (The related problem #1093 records that counterexamples can only come from good coefficients of deficiency ≥ 1.)
