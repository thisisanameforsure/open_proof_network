== Fix (api/opn_api/checks.py) ==

flagged_names(body): the names the linter flags. inlined_hole_names(ctx, target_id, defs,
flagged): a flagged name qualifies when a *node* module the service inlined declares it (the
node's Context, a used node's statement, a proposal's generated Context; never the caller's
text) and it is a hole of the target's graph.json (origin in opn_gate.graph.HOLE_ORIGINS) with
"-" made "_". The graph is read only when an inlined declaration is flagged; an unreadable graph
drops nothing (C7). without_generated_name_warning gains `inlined` and drops those as well as
the own name (T18 unchanged).
