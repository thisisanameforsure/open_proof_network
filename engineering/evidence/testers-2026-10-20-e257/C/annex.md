Informal argument for Erdős 257 by the greedy walk, written as the structure of a skeleton (one assembly, two holes) rather than as a proof: the second hole is the open core and the experts expect it to be false.

Write t(n) = 1/(2^n − 1) and, for a set A of positive integers, S(A) = Σ_{a ∈ A} t(a). Since t(n) ≤ 2^{1−n} for n ≥ 1, S(A) converges for every A. In Lean the root sums over A ⊆ ℕ, where t(0) = 1/0 = 0 is a junk value; the assembly passes to A \ {0}, which has the same sum and is still infinite.

Suppose A is infinite, 0 ∉ A, and S(A) = r is rational. The argument has two steps.

Step h_greedy (bookkeeping, provable). A is greedy for r: for every n ≥ 1, n ∈ A if and only if t(n) ≤ r − Σ_{a ∈ A, a < n} t(a). If n ∈ A the right-hand remainder is t(n) plus the tail over a ∈ A, a > n, which is nonnegative. If n ∉ A the remainder is that tail alone, which is at most Σ_{m > n} t(m), and the gap lemma (node spec-ddd99827, proved on this target) says that is strictly less than t(n). Uniqueness of representation (node spec-5e2e0890) is a corollary of this step: the greedy condition determines A from r recursively. Uniqueness is the refutation side's lemma, since it says the greedy set is the only candidate to check; a proof of the root does not need it, which is why it is not a hole here.

Step h_core (the open core). If G is a set of positive integers that is greedy for a rational r and S(G) = r, then G is finite. This is exactly the question: the root is false if and only if some rational's greedy walk runs forever and converges to that rational. The hypothesis S(G) = r cannot be dropped: a rational lying in a gap of the Cantor set of subset sums (for instance any rational strictly between Σ_{m ≥ 2} t(m) and t(1) = 1) has an infinite greedy walk whose sum is below r, so without the hypothesis the statement is trivially false instead of open. Kovač (erdosproblems.com/257, August 2025) expects the set of subset sums, a fat Cantor set, to contain rationals, and Hong (Zenodo 23287959, 2026, unrefereed) reports the greedy walk for 1/2 running to depth 10^8 without stalling; the walk begins 2, 3, 6, 7, 14, 20, 21, 26, 27, 32. A proof of node spec-a70fcca4 (1/2 is the sum over an infinite set) refutes this step and the root at once.

Assembly. From S(A) = r rational with A infinite, 0 ∉ A: h_greedy gives that A is greedy for r, and h_core gives that A is finite, a contradiction. So the root reduces to h_core, with h_greedy as the bookkeeping that makes the reduction honest.
