## Mathematics

Graham's gcd conjecture restricted to |A| = n, by the "largest element" certificate route (the docstring of variant-b89de5c4). Let M = max A. If some x in A has 18·gcd(M, x) <= M (n in place of 18), done with a = M. Otherwise each x != M is g·j with M = g·k, 1 <= j < k <= n-1, so r(x) := L·x/M = (L/k)·j with L = lcm(1..n-1), and r is injective on A \ {M}. S_n = {(L/k)·j} is partitioned into n-2 classes in which any two distinct c, d have n·gcd(c, d) <= c or <= d; pigeonhole puts two of the n-1 non-maximal elements x, y in one class, and gcd(r(x), r(y))·M = L·gcd(x, y) turns n·gcd(c, d) <= c into n·gcd(x, y) <= x.
