## Mathematics

- The assigned statement (Σ_p 2^{-p} irrational) was already proved on the record as `variant-09e95e7a` (graph PR #224). Not re-proposed.
- **Any base (variant-f592e3ab, PR #233).** `∀ b : ℕ, 2 ≤ b → Irrational (∑' p : Nat.Primes, (1 : ℝ) / (b : ℝ) ^ (p : ℕ))`. Proof (checked by /check, mode check, okay true; not yet prechecked): convert the `Nat.Primes` sum to an indicator sum over ℕ with `tsum_subtype`; with r = 1/b, if the sum were q with denominator k, take N = (k+1)! + 1; the k places after N are composite (j+2 divides (k+1)! + j + 2); the tail R after place N+1+k is positive (a prime beyond it) and at most 2·r^{N+1+k}; b^N·(finite part) is an integer Z; so b^N·num − k·Z = k·b^N·R lies in (0, k/b^k) ⊂ (0,1), impossible for an integer.
- **Every level set of ω (variant-14c6c771, PR #259).** `∀ m : ℕ, 1 ≤ m → Irrational (∑' n : ℕ, if ω n = m then (1 / 2 : ℝ) ^ n else 0)`. The root's number is Σ_m m·x_m with x_m this level-set number, so this says every summand is irrational (which does not by itself decide the root). Proof (checked by /check, okay true, no warnings; not yet prechecked): primes P(j,i) = `Nat.nth Nat.Prime (Nat.pair j i)` give, for each j, a product Q_j of m+1 primes, pairwise coprime across j; `Nat.chineseRemainderOfFinset` gives N with Q_j | N + j + 1 for all j < k, so each of the k places after N has ω ≥ m+1 (a window of zero digits); W = product of m primes, and W^(L+1) has ω = m and is ≥ L (infinitely many 1 digits); then the same integer-in-(0,1) contradiction with b = 2.
- **Prime powers, ω n = 1 (was variant-b43dd702, PR #242, withdrawn).** The m = 1 case with an elementary window (F² + j = j·(t·F+1), F = (k+1)!, so each has two distinct primes). Checked by /check, okay true. Withdrawn because #259 subsumes it; the file is kept in 69-B/prime-powers/ as an elementary alternative.
- **Factorial base, the root's own digits (variant-3a1bcb9a, PR #273).** `Irrational (∑' n : ℕ, (ω n : ℝ) / n.factorial)`. Proof (checked by /check, okay true, no warnings; not yet prechecked): 2ω(n) ≤ n because 2^ω(n) ≤ ∏_{p | n} p ≤ n; if the sum were a/q, take N = q + 2; N!·q and N!·(finite part) are integers, and N!·(tail) is positive (ω(N+1) ≥ 1) and, termwise, N!·ω(N+1+i)/(N+1+i)! ≤ (1/2)(N+1)^{-i} (from `Nat.factorial_mul_pow_le_factorial`), so it is at most (1/2)(1 − 1/(N+1))^{-1} ≤ 3/4. It shows exactly where base 2 is harder: the digits ω(n) are o(n), which beats n! but not 2^n.
- None of these is progress on the root's hard part: the root's digits ω(n) are unbounded and have no window of zeros, which is what this method needs.
