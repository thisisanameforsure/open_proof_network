- **spec-fa8046e4 `Opn.erdos_402_card_of_colouring`** (PR #230 open): the whole card-n argument as one reduction. For n ≥ 2 and L > 0, if every fraction L·j/k with 1 ≤ j < k < n is an integer lying in S, and c colours S with n − 2 colours so that any two distinct values a, b of the same colour have n·gcd(a,b) ≤ a or ≤ b, then every A with 0 ∉ A and |A| = n has a, b ∈ A with gcd(a,b) ≤ a/|A|.
