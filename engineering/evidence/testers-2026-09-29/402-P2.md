## Mathematics

- **The certificate route does not run out at 31.** For the "largest element" argument (402-D, 402-F:
  with M = max A, every other x is M·j/k with 1 ≤ j < k < n unless some gcd(M, x)·n ≤ M; map x to
  L·j/k, L = lcm(1..n−1), and colour those values with n − 2 colours so that two distinct values
  c, d of one colour have n·gcd(c, d) ≤ max(c, d)), the conflict graph on S_n (c ~ d when
  n·gcd(c, d) > max(c, d), equivalently the reduced ratio c/d has both terms < n) has maximum

  colouring (greedy.py) uses exactly n − 2 colours for **every n from 3 to 90 except 66**, and a tabu search colours n = 66. So

- **What this does and does not buy.** The hole after this skeleton is still Graham's conjecture
  for primitive sets of size ≥ 45 (not prime, not prime + 1), i.e. the Balasubramanian–Soundararajan
  range; finite certificates can push the bound up (every size to 90 but 66 has one by greedy),
  but each size costs more kernel time and more text (n = 45 and 46 together: 6.8 s of /check in the
  table encoding; the text passes 200 kB before n = 55), so this route shrinks the hole, it never
  closes it.
- **Why the certificate is the right object.** A set A of size n with no good pair and largest
  element M gives n − 1 fractions x/M < 1 whose pairwise ratios, reduced, have both terms < n:
  a clique of size n − 1 in the conflict graph G_n. Conversely such a clique is realised by
  multiplying out a common denominator. So Graham's bound for size n is exactly ω(G_n) ≤ n − 2,
  and the clique {1/(n−1), …, (n−2)/(n−1)} shows equality. An (n − 2)-colouring is a certificate
  of that bound that the kernel checks cheaply, and the computations say χ(G_n) = ω(G_n) = n − 2
  for every n tested (3 to 90). An explicit colouring for all n would be an elementary proof of the
  Balasubramanian–Soundararajan theorem, so none should be expected to be easy.
