- **Graham's bound for |A| = p + 2, every prime p: a short proof** (402-W3-2/annex-draft-p-plus-2.md).
  Suppose every pair's reduced ratio has both terms ≤ p + 1. Classify elements by their p-free part
  mod p (p − 1 classes). In one class every ratio is p + 1, p or (p + 1)/p, so a class holds at most
  3 elements, and a 3-element class contains a ratio-(p + 1) pair. Two same-class pairs in different
  classes can coexist only as a ratio-p pair beside a ratio-(p + 1)/p pair (a four-line case analysis
  on the reduced ratio y = u/v). Counting gives |A| ≤ p + 1. Checked: the two lemmas exhaustively in
  exact rational arithmetic for all primes p ≤ 47 (pplus2_exhaustive.out), the conclusion by an
  independent clique search for p ≤ 13 (pplus2_clique.out). The general argument is not
  machine-checked. It uses none of the hole's extra hypotheses, so a formal version would take
  |B| = p + 2 out of the hole #289 creates (45, 49, 55, 61, 63, … among sizes ≥ 45) the way prime
  and prime + 1 are already out. Formalising it is a real Lean project (one declaration, no
  helpers), not a certificate; I have not started it.
- **Where this sits.** The argument is the residue-class-mod-p method; as I recall (not checked:
  the container cannot reach arxiv.org), the Szegedy (1986) and Zaharescu (1987) proofs of Graham's
  conjecture for all large n use a prime p close to n in the same spirit, which is why n = p + k for
  small k is the natural next family. Whether the same counting closes n = p + 3 (within a class the
  ratios (p + 2)/2 and its relatives join the three above) I have not worked out. I also considered
  and rejected folding the p + 2 case into the child skeleton as a second hole: a hole inherits every
  hole before it as a hypothesis, so whichever of the two holes comes second would need the first
  one *proved* inside its witness (guide, "Witness it"). The p + 2 statement is best proposed as its
  own node, if anyone wants it on the record; I opened nothing.
- **The same counting may reach p + 3 and p + 4** (exploration, Python only: 402-W3-2/pplusk_excess.py
  and .out). Call the *excess* of a compatible set S (all reduced ratios with terms ≤ p + k − 1) the
  number |S| − (residue classes S meets); a class-counting proof of Graham's bound for |A| = p + k
  needs excess ≤ k, since then |S| ≤ (p − 1) + k. An exhaustive search over all maximal compatible
  sets finds the largest excess to be exactly k for every k = 2, …, 6 and every prime p ≤ 47 (70
  cases, 5 min 46 s). Within one class for k = 3 the ratios are p, p + 1, (p + 1)/p and (p + 2)/2,
  and a class still holds at most 3 elements (pplus3_explore.out); the cross-class coexistence of
  pair types is the same for every p from 5 to 31 (AB, BB, BP, BQ, PQ; pplus3_types.out), but for
  k = 3 pairwise rules no longer suffice (BB coexists), so a proof needs a finer count. Since every
  n has a prime p < n, "excess ≤ n − p" for all p would be Graham's conjecture itself; the useful
  form is a fixed small k with p large. I have no proof beyond k = 2.
