## Mathematics

- **variant-892f5809 (card 9)**: proved. `402-A/proof_v2.lean`, verdict pass from precheck 01M3Q9FR5GV25452BZMBG6XKSJ; PR #252 gate green. Route (the node's own docstring): M = max A; if some x has 9·gcd(M,x) ≤ M, done with (M,x). Otherwise M = k·g, x = j·g (g = gcd(M,x)) with 1 ≤ j < k ≤ 8, so 840·x = c·M with c = 840j/k one of 21 values; a 7-class split of the 21 values, each class pairwise good (9·gcd(c,d) ≤ max), plus pigeonhole on the 8 other elements, and gcd(c,d)·M = 840·gcd(x,y) carries the bound back.
- **Budget trick — corrected ~19:54Z, my first diagnosis was wrong.** What cost 18.7 s in `t_pair.lean` was not the 441 pairs nor the if-chain colour: it was the *untyped* list literals (`∀ a ∈ [105, 120, …]` with nothing fixing the element type before `a.gcd b`).
