$$\forall n \in \mathbb{N},\ \forall A \subset \mathbb{N}\ \text{finite}\ \text{nonempty},\ M = \max A:\ 0 \notin A,\ \bigl(\forall x \in A,\ M < \gcd(M, x) \cdot n\bigr) \Rightarrow \forall x \in A \setminus \{M\}\ \exists\, j, k \in \mathbb{N}:\ 1 \le j < k < n,\ k x = j M$$

For a finite nonempty set A of positive integers with largest element M and any n ∈ ℕ: if M < n·gcd(M, x) for every x ∈ A, then every element other than M is (j/k)·M for some 1 ≤ j < k < n, written as the equation k·x = j·M over ℕ.
