Split the exceptional pairs at n = k²: for n ≥ k² the bound is n/k (finitely many n for each k, and k bounded), for 2k ≤ n < k² the bound is k and k is bounded.

The holes are `h_fixed_k` (for each k, finitely many n ≥ k² with lpf C(n,k) > n/k), `h_large_n` (a bound K on k when n ≥ k² and lpf C(n,k) > n/k) and `h_small_n` (a bound K on k when 2k ≤ n < k² and lpf C(n,k) > k). The assembly writes the exceptional set as a union over k ≤ max(K_A, K_B) of the finite set from `h_fixed_k` and the finite range n < k², using that max(n/k, k) is n/k when n ≥ k² and k otherwise.
