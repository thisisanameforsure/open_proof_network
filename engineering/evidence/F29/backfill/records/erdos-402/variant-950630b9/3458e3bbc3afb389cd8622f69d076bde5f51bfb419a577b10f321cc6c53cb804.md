$$\forall A \subset \mathbb{N}\ \text{finite}:\ 0 \notin A,\ \bigl(\exists\, m \in A,\ \exists\, b \in A:\ (\forall c \in A,\ c \le m) \wedge \gcd(m, b) = 1\bigr) \Rightarrow \exists\, a, b \in A:\ \gcd(a,b) \le \frac{a}{|A|}$$

For a finite set A of positive integers in which some maximal element m is coprime to some element b, there are a, b ∈ A (possibly equal) with gcd(a, b) ≤ a/|A|. The division is in ℚ.
