$$0 \notin A,\ A \ne \emptyset,\ \gcd(A) = 1,\ \bigl(\forall a, b \in A\ \exists\, u, v:\ 0 < u \le |A|,\ 0 < v \le |A|,\ \gcd(u,v) = 1,\ a v = b u\bigr) \Rightarrow \exists\, a, b \in A:\ \gcd(a,b) \le \Bigl\lfloor \frac{a}{|A|} \Bigr\rfloor$$

Assuming the Farey-structure claim as a hypothesis (for every finite A ⊂ ℕ with 0 ∉ A and every m, a ≤ m·gcd(a, b) for all a, b ∈ A implies that each pair has a·v = b·u for some coprime u, v with 1 ≤ u, v ≤ m) and the reduction to primitive sets as a hypothesis (for every finite nonempty A ⊂ ℕ with 0 ∉ A, the bound for every B of the same size with gcd(B) = 1 gives the bound for A): every finite nonempty A ⊂ ℕ with 0 ∉ A whose elements have greatest common divisor 1, and in which every pair a, b satisfies a·v = b·u for some coprime u, v with 1 ≤ u, v ≤ |A|, contains a pair with gcd(a, b) ≤ a/|A|. As written, the coercion arrows carry no target type and elaborate as the identity on ℕ, so every a/|A| here, including the one inside the second hypothesis, is natural-number division rounding down, not the rational division of the parent statement; a and b may coincide.
