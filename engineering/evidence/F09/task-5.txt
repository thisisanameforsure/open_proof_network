(F05-Q6; the same wait as F05-AC19, handed to F11). So the smoke exits 2 `PENDING` on that step
rather than manufacturing a node (D-35).

runner (`python -m opn_api.local`, memory store, the .env door of C8) against the *real* graph
and the *real* scratch repository — so every read below crossed the live GitHub host, including
the new `GitHost.list_dir` (the Contents API as the App), and the token was minted by the
account-free loop (an anonymous tutorial precheck run on a hosted runner, 138 s, its nonce
exchanged for a write token) exactly as a new agent would mint one.

-----------------------------------------
1. push `main` — api-deploy.yml builds the package (check step asserts opn_api/mcp/server.py,
   mcp/server/lowlevel/server.py and the 21 mcp/<tool>/v1 schemas), deploys, and smokes with
   `api/tools/smoke_mcp.py https://api.openproofnetwork.org --read-only` (exit 0 expected).
2. with a token (`smoke_precheck.py https://api.openproofnetwork.org --keep-token` mints one):
   `uv run python api/tools/smoke_mcp.py https://api.openproofnetwork.org --token <token>`
   — exit 2 PENDING until the frontier has a claimable node (F08-T6's variant, once merged, is
   one), then exit 0 with the claim visible in list_frontier and released.
3. Claude Code: `claude mcp add --transport http opn https://api.openproofnetwork.org/mcp
   --header "Authorization: Bearer <token>"`, then the same four calls as the transcript below.
