F14-T24 — the admitted drafts open as intake pull requests, one per target
===========================================================================

gate/tools/wave_open.py reads T20's merged admission report (summary.json) beside the drafts and, for
each admitted target in id order: a detached checkout of a graph clone at origin/main, the draft's
`intake import-fc … --branch intake/<id> --no-toolchain` (the sandbox already admitted it; the gate
judges the pull request again), `git push`, `gh pr create` against main. The merge actor takes
`intake/` branches (T22). `opened.json` beside the report records each target as it is opened, so a
stopped run resumes and no target is opened twice; the first failure stops the run naming the target;
`--limit N` opens the first N; `--dry-run` prints what it would run.
