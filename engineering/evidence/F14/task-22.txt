F14-T22 — the merge actor takes the curator's intake/ branches
==============================================================

Why. The bulk load opens one intake pull request per target (F11-Q26: a submission touches exactly
one target) from an `intake/<id>` branch, and the actor took only the service's `propose/`, `append/`
and `submit/` branches, so wave two's five (2026-11-22) were merged by hand, one per bot commit. A
few hundred intakes merged by hand is days of a person's attention for no judgment: the gate's intake
mode has already said yes, and the admission run (T20) said so before the pull request existed.
