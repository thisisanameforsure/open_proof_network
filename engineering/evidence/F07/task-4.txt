THE GAP THIS TASK FOUND, AND WHY IT MATTERED
--------------------------------------------
A hole's type is not a statement. The extractor reported `q` for a hole inside
`∀ p q : Prop, p ∧ q → q ∧ p`, and `q` is a bound variable, not a proposition anyone can state on
its own — so a child node built from it would have had a Statement.lean that does not elaborate,
and D-29's "the holes enter the frontier as children" would have produced nodes the gate rejects.

`OpnGate.Holes` now reports `closed_type` alongside `type`: the same obligation closed over the
binders it sat under.

  right : q          ->  ∀ (p q : Prop), p ∧ q → q
  left  : p          ->  ∀ (p q : Prop), p ∧ q → q → p     (it sits under `have right` too)

The offload rule got sharper for free: the closed form is compared against the statement as well,
so `have same : q ∧ p := sorry` inside the same binders is caught as the goal restated whichever
way it is written. The `RestateConclusion` fixture shows exactly that in the golden.

THREE SCHEMA VERSIONS, AND WHY EACH
-----------------------------------
D-34 says versioned, never edited, so R8's two new statuses cost new versions:

  graph/v2          status gains refuted and defective, and each node gains `cause` — the
                    machine-readable reason a derived status is what it is (dep-refuted,
                    witness-missing). v1 has no field to put that in.
  targets-index/v2  node_counts gains the same two keys, so the counts still sum.
  meta/v3           already existed; the scaffold now picks it when the origin needs it
                    (skeleton-hole) and keeps meta/v2 otherwise, so nothing committed churns.

The site reads both product versions rather than moving its pin: a consumer parses by version and
old snapshots keep rendering (D-34). Its status vocabulary gained the two words; it already fell
back to the raw token for anything it did not know, so this is presentation, not correctness.

The info.json schema index moved again, so the three F03 goldens and the api's copy were
regenerated in this commit — the diff is the index, the `cause` field and the two schema names,
and no product drifted otherwise.
