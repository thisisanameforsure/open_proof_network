WHERE THE TIME GOES
1. Queue wait before the job: ~0.1 min, except a burst at 14:52–15:10Z (1–11 min, runner
   availability). Not a lever.
2. The post-merge job: building merges 8.9 min median = setup 0.6 + classify 0.1 + re-derive 3.1
   (image pull ~2 min inside it) + JOIN 3.0 + products 1.4 + push 0.2. Non-building: the batch's
   head run (26 runs) 8.25 min median, of which JOIN is 5.5 min and products 1.3; the other runs
   of a batch end in 0.3 min and leave their merges to the head (F07-T45), which is why an append
   waits as long as a proof.
3. JOIN is the closure sweep (F28-T9, `opn-gate close --all --no-build`), run on every merge.
   Both logs read show the same two joins attempted and failing, every run:
     erdos-1050  erdos-1050@1 join-failed "hole borwein: no child closes it: erdos-1050--h1-v2:
                 erdos_1050__h1 is not declared"
     tutorial    variant-93e79cb5@2 join-failed "hole h₁: no child closes it: variant-93e79cb5--h3:
                 variant_93e79cb5__h3 is not declared"
   In #1516's run (an append batch head) the sweep pulled the Mathlib image (118 s) and the core
   image (43 s) only for these, and spent ~2.4 min composing the erdos-1050 join; nothing was
   recorded. So an append merge DOES pull the 3.8 GB Mathlib image — not for a replay (the
   re-derive step is skipped) but for the sweep's dead joins.
4. The products never ride in the job's own commit: all 52 `gate: #N` commits of 2026-11-19
   carry the record only (none touches frontier.json). The job runs ~9 min, main always moves
   meanwhile, so publish (F07-T55) takes the catch-up path: record only, then dispatches
   render.yml. Merge→record median 8.8–9.1 min; record→products median 3.7 (non-building) / 4.2
   (building) min, max 23.
5. render.yml: concurrency group `render` (one running, one pending): median queue 120 s (max
   300); job median 264 s (max 744) = render 81 s + commit-and-push 157 s median (max 617),
   because a refused push renders again on main as it is (F07-T60), and main moves under an
   81 s render during a burst.
6. The cache job (building merges only) runs after the record is pushed: median 7.7 min
   (2.5–14.8). It does not delay the products. The outline job likewise (~11 min on #1600).

WHAT WAS CHANGED: nothing in the workflow. Every lever found touches what the brief excludes:
 a. Fix the two dead joins (F28's closer cannot find a revised child's declaration under its
    original theorem name, `erdos_1050__h1` for `-h1-v2`, and the same for a tutorial-variant
    hole). Fixing them makes each join succeed once and record a closure, i.e. it changes what
    is attested; it is a closure bug for the lead to file (F28), not a speed-up to make here.
    Expected saving once fixed: ~3 min of every building merge's job and ~5 of an append batch
    head's (no image pull, nothing to compose), which should also let more first pushes land
    with their products and skip the render.yml round (point 4).
 b. Memoise failed joins keyed by (node, link, every input's file hashes, render pin): a join
    that failed on identical inputs fails again, and a failed join records nothing, so skipping
    it changes no record. Needs a store across runs (actions/cache on main) and a network change
    behind a re-pin; a new mechanism, so described, not built.
 c. Skip the sweep on a merge that builds nothing: NOT safe as is. F32-Q11 relies on the next
    sweep (whatever merges next) to close a parent completed by the previous run's born-proved
    holes, so skipping on appends defers closures (changes when they are attested).
 d. Run the sweep after the record push (like cache/outline): changes which commit carries the
    closure records and what the merge's products show. Excluded.
 e. Pre-pull the image in the background at job start: same digest, no semantic change, but the
    pull already starts ~35 s into the job; under a minute to gain. Not worth a change.

ANALYSIS SCRIPT (run: python3 analyse.py <dir with job_*.json, log.txt> <graph checkout>):
"""B2: the post-merge timing of the 2026-11-19 run, from gh run JSON and the graph's first-parent log."""
import glob, json, re, subprocess, sys, statistics
from datetime import datetime, timezone

D = sys.argv[1]
GRAPH = sys.argv[2]

def t(s):
    return datetime.fromisoformat(s.replace("Z", "+00:00"))

log = []
for line in open(f"{D}/log.txt"):
    h, c, a, s = line.rstrip("\n").split("|", 3)
    log.append((h, t(c), s))
log.reverse()  # oldest first

def touches_products(sha):
    out = subprocess.run(["git", "-C", GRAPH, "show", "--name-only", "--format=", sha], capture_output=True, text=True).stdout
    return any(p == "frontier.json" or re.match(r"targets/[^/]+/graph\.json$", p) for p in out.split())

runs = {}
for f in glob.glob(f"{D}/job_*.json"):
    d = json.load(open(f))
    m = re.match(r"Merge pull request #(\d+) from \S+?/(\S+)", d["displayTitle"])
    if m:
        runs[int(m.group(1))] = (d, m.group(2))

GROUPS = [
    ("setup", lambda n: n in ("Set up job",) or n.startswith("Run actions/checkout") or n.startswith("Check out") or n.startswith("Run astral") or n.startswith("Find the merged")),
    ("classify", lambda n: n.startswith("Classify")),
    ("rederive", lambda n: n.startswith("Re-derive")),
    ("join", lambda n: n.startswith("Join")),
    ("products", lambda n: n.startswith("Regenerate")),
    ("push", lambda n: n.startswith("Commit the attestation")),
]
rows = []
for i, (h, tm, s) in enumerate(log):
    m = re.match(r"Merge pull request #(\d+) from \S+?/(\S+)", s)
    if not m or tm < t("2026-11-19T12:30:00Z"):
        continue
    n = int(m.group(1))
    branch = m.group(2)
    credit = rendered = None
    for h2, t2, s2 in log[i + 1:]:
        cm = re.match(r"^gate:((?: #[0-9]+)+)", s2)
        if credit is None and cm and f"#{n}" in cm.group(1).split():
            credit = (h2, t2, s2)
            if touches_products(h2):
                rendered = t2
                break
            continue
        if credit is not None and s2.startswith("gate: render"):
            rendered = t2
            break
    row = {"pr": n, "kind": branch.split("/")[0], "merged": tm}
    row["credit_s"] = (credit[1] - tm).total_seconds() if credit else None
    row["credited_by"] = credit[2][:60] if credit else None
    row["products_s"] = (rendered - tm).total_seconds() if rendered else None
    if n in runs:
        d, _ = runs[n]
        pm = next((j for j in d["jobs"] if j["name"].startswith("postmerge")), None)
        cache = next((j for j in d["jobs"] if j["name"].startswith("olean cache")), None)
        if pm and pm.get("startedAt"):
            row["queue_s"] = (t(pm["startedAt"]) - t(d["createdAt"])).total_seconds()
            row["job_s"] = (t(pm["completedAt"]) - t(pm["startedAt"])).total_seconds() if pm.get("completedAt") else None
            row["conclusion"] = pm["conclusion"]
            for g, pred in GROUPS:
                tot = 0.0
                for st in pm["steps"]:
                    if pred(st["name"]) and st["conclusion"] not in ("skipped",) and st.get("completedAt") and st.get("startedAt"):
                        tot += (t(st["completedAt"]) - t(st["startedAt"])).total_seconds()
                row[g] = tot
            rd = [st for st in pm["steps"] if st["name"].startswith("Re-derive")]
            row["builds"] = bool(rd and rd[0]["conclusion"] == "success")
        if cache and cache.get("startedAt") and cache.get("completedAt") and cache["conclusion"] != "skipped":
            row["cache_s"] = (t(cache["completedAt"]) - t(cache["startedAt"])).total_seconds()
    rows.append(row)

def fmt(x):
    return "-" if x is None else f"{x/60:5.1f}"

cols = ["queue_s", "setup", "classify", "rederive", "join", "products", "push", "job_s", "credit_s", "products_s", "cache_s"]
print("All times in minutes. merged = merge commit time (UTC). credit = the `gate: #N` commit after the merge;")
print("products = the first commit after the merge that carries this merge's products (its own gate commit")
print("when that touched frontier.json/graph.json, else the next `gate: render`).")
print()
print(f"{'PR':>5} {'kind':7} {'build':5} {'merged':8} " + " ".join(f"{c[:-2] if c.endswith('_s') else c:>8}" for c in cols) + "  credited by")
for r in rows:
    print(f"{r['pr']:>5} {r['kind']:7} {str(r.get('builds','?'))[:5]:5} {r['merged'].astimezone(timezone.utc).strftime('%H:%M:%S'):8} " + " ".join(f"{fmt(r.get(c)):>8}" for c in cols) + "  " + (r["credited_by"] or "-"))
print()
for label, sel in (("building merges", lambda r: r.get("builds") is True), ("non-building merges (appends etc.)", lambda r: r.get("builds") is False)):
    sub = [r for r in rows if sel(r)]
    print(f"{label}: n={len(sub)}")
    for c in cols:
        vals = [r[c] for r in sub if r.get(c) is not None]
        if vals:
            print(f"  median {c:10} {statistics.median(vals)/60:5.1f} min   (min {min(vals)/60:.1f}, max {max(vals)/60:.1f}, n={len(vals)})")
json.dump([{k: (v.isoformat() if isinstance(v, datetime) else v) for k, v in r.items()} for r in rows], open(f"{D}/rows.json", "w"), indent=1)
