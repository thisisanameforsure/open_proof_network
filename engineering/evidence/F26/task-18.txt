== For agent S (T19): the supersession function ==

  opn_gate.review.latest_of(named: Iterable[tuple[str, dict[str, Any]]]) -> list[dict[str, Any]]
      The pair records in force, one per (a, b), sorted by (a, b), from (file name, record) pairs
      in any order. Pure: no disk, so the service can call it on what it read through the host.
  opn_gate.review.latest_pairs(base: Path) -> list[dict[str, Any]]
      The same over a target's review/ directory on disk (reads base / "pairs").
  opn_gate.review.in_order(named) -> list[dict]       every record, oldest first
  opn_gate.review.generation(name: str) -> int        k from <a>--<b>--<date>-<k>.yaml, else 1

The rule (in_order): a record's place is (date, generation read from the file name, file name);
the last of a pair in that order is in force. Nothing is renamed and every published name keeps a
place (D-34): <a>--<b>.yaml is generation 1, the job's later records are --<date>-<k>.yaml with
k >= 2, so on one day the first record is oldest and -10 is newer than -2. review._pairs (derive,
open_pairs, split_variants) and the job's _load (review_pairs.latest) both go through it.
