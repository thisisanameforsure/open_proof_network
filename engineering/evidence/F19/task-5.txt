== What it does ==
workflow_dispatch (graph_sha required, target optional); permissions: contents: read; no secret.
1. Clone the graph (blob-less) and check out graph_sha (a 7-40 hex sha, refused otherwise).
2. List the targets (targets/*/gate-spec.json, or the one named) and their network_commit; refuse
   if they pin more than one commit (name one target), or if the pin is not a sha.
3. Check out the network at that pin into network-pin (no persisted credential), setup-uv, make
   room for a Mathlib image.
4. `uv sync` the pinned network; refuse by name (::error::, exit 1) if its own help has no
   `outline` command: re-pin first. Per target: pull its devcontainer_ref, run
   `opn_gate.cli outline --graph graph --commit <sha> --target T --dest outlines --image <ref>
   --no-build`, write report-T.json, add a row (written / already there / failed) to the step
   summary, remove the image. Exit 1 at the end if any target named a failure.
5. Always upload `outlines/` (targets/<T>/outlines/<hash>.json, only what was new) and the reports
   as the artifact `outlines`, for the curator to read and commit by hand. Nothing is pushed.
