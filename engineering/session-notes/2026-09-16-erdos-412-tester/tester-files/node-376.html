Informal reduction for Erdős 376 (the set of n with C(2n,n) coprime to 105 = 3*5*7 is infinite). Lemma 1 (Kummer): for a prime p, the exponent of p in C(2n,n) is the number of carries when adding n+n in base p. If every base-p digit of n is < p/2, there are no carries, so p does not divide C(2n,n). Hence if the base-3 digits of n are <= 1, base-5 digits <= 2 and base-7 digits <= 3, then C(2n,n) is coprime to 105. Lemma 2 (open core): there are infinitely many n whose base-3, base-5 and base-7 digits simultaneously satisfy those bounds. This is the genuinely open part (Erdős–Graham–Ruzsa–Straus give density-type results for two primes; three primes is open). Assembly: the set in Lemma 2 is contained in the target set, so the target set is infinite.
