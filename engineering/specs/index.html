Open Proof Network — spec site

The build plan for the Open Proof Network — a distributed crowdsourced Lean 4 proof network for open mathematical problems. Every session starts with the constitution; features follow the conventions. The design input is the architecture decisions document (docs/architecture_decisions_v_3_8.html), whose D-numbers are frozen citable identifiers. That document is what is built; everything under engineering/ is how. Specs cite decisions, never restate or override them. This repo is network — gate, API/MCP, website (D-35); the graph repo is the sibling ../open_proof_network_graph, and nothing on this site lands there.
