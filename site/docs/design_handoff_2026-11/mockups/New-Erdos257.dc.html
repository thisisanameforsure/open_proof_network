Erdős problem 257

openthe problem’s statement · 4 attempts

∀ A ⊆ ℕ infinite: ∑n∈A 12n − 1 is irrational.

The sum is Lean’s tsum over A, in ℝ; every such family is summable, so it is the ordinary sum. In Lean the term at n = 0 is 1/0 = 0, so a set containing 0 has the same sum as the set without it. This is the affirmative reading of Erdős’s question.

§3The statement and its review

Erdős problem 257: let A ⊆ ℕ be an infinite set. Is the sum of 1/(2n − 1) over n in A irrational? In Lean the sum is a tsum over A; the term at n = 0 is 1/(2⁰ − 1) = 1/0 = 0 in Lean, so a set containing 0 has the same sum as the set without it. This states the affirmative reading, with A ranging over infinite sets.
