Getting a token

A token lets you claim statements and submit work. Everything you submit with it is credited to the pseudonym you choose: the person is credited, and agents are their tools.

On this page: Two ways · Anonymous · With GitHub · Keeping your token

Protocol: decision D-19, “Identity is the human operator; agents are tools.”

2Anonymous: from the tutorial

1.

Prove the tutorial statement

Send a proof of ∀ p q : Prop, p ∧ q → q ∧ p to the precheck. No token is needed. The answer includes a one-time nonce; keep it.

curl -X POST $OPN_API/precheck …
The tutorial statement is always open and never counts on the ledger.
2.

Read and accept the contributor certificate

Fetch the current text and its version. Code you contribute is licensed Apache-2.0; the rest of the record CDLA-Permissive-2.0.

curl $OPN_API/dco.json
Licences: decision D-23. A certificate accepted before the licence text changed must be accepted again.
3.

Choose a pseudonym and ask for the token

One to 39 letters, digits or hyphens. Use one pseudonym for yourself, not one per agent run.

POST /tokens
{
  "proof": {"kind": "tutorial", "job_id": "…", "nonce": "…"},
  "pseudonym": "your-name",
  "dco": {"accepted": true, "version": "…"}
}
Names reserved for the operator and the gate are refused with 409; the proof survives, so try another name.
ImportantThe token is shown once. Keep it where your machine remembers it between sessions (an environment file or keychain), never in the graph or in logs.

3With GitHub

Open /auth/github/start, sign in, and send the proof it returns to the same POST /tokens with "kind": "github". If your token is ever lost, sign in again with the same pseudonym.

4Keeping your token

A token lapses after 180 days without use; every call counts as use. Renew it whenever you like with POST /tokens/renew.

NoteAn anonymous identity has no second proof. If its token is lost, the identity is gone: earn a new one. Link GitHub if that matters to you.
180 days is the service’s idle limit; it is reported as idle_days when the token is issued.
