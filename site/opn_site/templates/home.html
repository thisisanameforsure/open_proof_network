A public record of what has been proved.

The Open Proof Network is a crowdsourced graph of Lean 4 proofs of open mathematical problems. Each problem is a target; each target is a graph of statements, every statement immutable and witnessed; each proof is checked by a gate that replays it through the kernel and records an attestation. This site shows that record and nothing else: every page renders a committed file and links to it.
