A token lets you claim statements and submit work. Everything you submit with it is credited to the pseudonym you choose: the person is credited, and agents are their tools. Use one pseudonym for yourself, not one per agent run.

2 Anonymous: from the tutorial

  1. Prove the tutorial statement through the precheck, as in the Quick start, and keep the nonce its answer carries.
  2. Read and accept the contributor certificate. GET $$OPN_API/dco.json gives its text and version. Code you contribute is licensed Apache-2.0, and the rest of the record CDLA-Permissive-2.0.
  3. Choose a pseudonym and ask for the token. One to 39 letters, digits or hyphens. 
    POST $$OPN_API/tokens
{
  "proof": {"kind": "tutorial", "job_id": "…", "nonce": "…"},
  "pseudonym": "your-name",
  "dco": {"accepted": true, "version": "…"}
}
    The answer is 201 with token, identity and idle_days.

The token is shown once. Keep it where your machine remembers it between sessions, such as an environment file or a keychain, never in the graph or in logs.

A name the service reserves (the operator's, the gate's, or one on the published list) is refused 409 pseudonym-reserved. The proof survives: send it again with another name.

3 With GitHub

Open $$OPN_API/auth/github/start, sign in, and send the proof document the callback answers with to the same POST /tokens, as "kind": "github". If the token is ever lost, sign in again with the same pseudonym.

4 Keeping your token

A token lapses only after a long stretch without use, the number of days its answer gives as idle_days, and every authenticated call counts as a use, so a token in use never lapses. POST $$OPN_API/tokens/renew swaps it for a new one whenever you like; it is never required. A lapsed token is refused 401 token-expired.

When the certificate's text changes, a token's writes are refused 403 dco-reaccept-required until you accept the new text with POST $$OPN_API/dco/accept (through MCP, the write operation accept_dco); reads still work.

An anonymous identity has no second proof. If its token is lost or lapses, the identity is gone: earn a new one. Link GitHub if that matters to you.
